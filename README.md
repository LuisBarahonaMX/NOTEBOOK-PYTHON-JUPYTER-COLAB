## 6. K-Nearest Neighbors Classification

**Notebook:** `LB Clasificacion_vecinos_cercanos.ipynb`

### Overview

This notebook introduces classification based on neighboring observations.

K-Nearest Neighbors (KNN) is a supervised learning algorithm that assigns a class using the labels of nearby observations in feature space.

### Mathematical Principle

The algorithm relies on a distance function.

A common example is Euclidean distance:

```text
d(x, y) = sqrt(Σ(xi - yi)²)
```

### Main Concepts

- Supervised classification.
- Distance metrics.
- Feature representation.
- Number of neighbors.
- Decision boundaries.
- Feature scaling.
- Model evaluation.

### Workflow

A standard KNN workflow involves:

1. Loading labeled observations.
2. Selecting numerical features.
3. Preparing training and testing data.
4. Scaling features when appropriate.
5. Selecting the number of neighbors.
6. Fitting the classifier.
7. Evaluating predictions.

### Practical Applications

KNN can be used for introductory experiments in:

- Pattern recognition.
- Customer classification.
- Similarity analysis.
- Educational Machine Learning.
- Anomaly exploration.

### Limitations

KNN may become computationally expensive when the training dataset is large.

Its performance can also depend strongly on feature scaling, dimensionality, and the selected distance metric.

## 14. Self-Organizing Maps and Unsupervised Learning

**Notebook:** `LB SOM_Aprendizaje_No_Supervisado_Optimizacion.ipynb`

### Overview

This notebook explores Self-Organizing Maps (SOM), an unsupervised learning approach inspired by neural computation.

SOM algorithms represent high-dimensional observations using a structured arrangement of units.

### Main Concepts

- Unsupervised learning.
- Competitive learning.
- Best Matching Unit.
- Neighborhood relationships.
- Weight updates.
- Dimensionality reduction.
- Topological organization.

### Conceptual Workflow

1. Initialize a grid of model units.
2. Select an input observation.
3. Identify the closest unit.
4. Update the winning unit and its neighbors.
5. Repeat across the dataset.
6. Examine the resulting representation.

### Mathematical Idea

A SOM updates model weights based on their relationship to the selected input.

```text
w_new = w_old + α × h × (x - w_old)
```

Where:

- α is the learning rate.
- h represents neighborhood influence.
- x is the input observation.

### Applications

- Exploratory clustering.
- Customer segmentation.
- Pattern visualization.
- Dimensionality reduction.
- Unsupervised representation learning.

### Limitations

The results depend on the map structure, learning rate, initialization, and training configuration.

## 16. SARIMA and Prophet Forecasting

**Notebook:** `LB Notebook_SARIMA_Prophet_Correcta.ipynb`

### Overview

This notebook explores statistical forecasting with SARIMA and Prophet.

Both methods are used to model temporal patterns, but they rely on different statistical frameworks.

### SARIMA

Seasonal Autoregressive Integrated Moving Average incorporates autoregressive, differencing, moving-average, and seasonal components.

The general notation is:

```text
SARIMA(p,d,q)(P,D,Q,s)
```

Where:

- p represents the nonseasonal autoregressive order.
- d represents nonseasonal differencing.
- q represents the nonseasonal moving-average order.
- P, D, and Q represent seasonal orders.
- s represents the seasonal period.

### Prophet

Prophet models time series through components such as trend and seasonality.

It is designed to provide a practical forecasting workflow for many business-oriented time series.

### Research Objectives

- Study statistical time series methods.
- Understand seasonality.
- Compare forecasting approaches.
- Explore model configuration.
- Interpret prediction errors.
- Understand model assumptions.

### Potential Evaluation Metrics

- MAE.
- RMSE.
- MAPE.
- Forecast residual analysis.

### Limitations

Model performance depends on data frequency, historical coverage, structural changes, and validation methodology.

## 19. ARIMA Time Series Modeling

**Notebook:** `LB_ARIMA_[clase].ipynb`

### Overview

This notebook explores the Autoregressive Integrated Moving Average (ARIMA) methodology.

ARIMA combines three components:

- Autoregression.
- Differencing.
- Moving averages.

### Model Notation

```text
ARIMA(p, d, q)
```

### Main Concepts

**Autoregressive component (p)**

Models relationships between an observation and previous observations.

**Integrated component (d)**

Uses differencing to address certain forms of nonstationarity.

**Moving-average component (q)**

Models dependencies involving previous forecast errors.

### Analytical Procedure

A standard ARIMA study involves:

1. Visualizing the historical series.
2. Examining stationarity.
3. Considering differencing.
4. Studying autocorrelation.
5. Selecting model orders.
6. Fitting the model.
7. Evaluating residuals.
8. Assessing forecasting accuracy.

### Applications

- Economic forecasting.
- Demand estimation.
- Financial analysis.
- Operational planning.

### Limitations

ARIMA is not automatically suitable for every time series.

## 27. Association Rule Mining and Market Basket Analysis

**Notebook:** `LB Minería_de_reglas_de_asociación_[análisis_de_la_canasta_de_compras_clase].ipynb`

### Overview

This notebook explores Association Rule Mining through market basket analysis.

The objective is to identify relationships between items that frequently appear together in transactional datasets.

### Main Concepts

- Transactions.
- Itemsets.
- Frequent itemsets.
- Association rules.
- Support.
- Confidence.
- Lift.

### Support

Measures how frequently an itemset appears across transactions.

```text
Support(A) = Transactions containing A / Total transactions
```

### Confidence

Measures the proportion of transactions containing A that also contain B.

```text
Confidence(A → B) = Support(A ∩ B) / Support(A)
```

### Lift

Evaluates the strength of an association relative to what would be expected if the items were independent.

```text
Lift(A → B) = Confidence(A → B) / Support(B)
```

### Applications

- Retail analytics.
- Product bundling.
- Cross-selling.
- Transaction analysis.
- Recommendation research.

### Limitations

Association rules identify statistical co-occurrence patterns.

They do not establish causal relationships.

## 31. Jacobi Numerical Method — Large Matrix Experiment

**Notebook:** `LB Metodo_Jacobi_Colab_ Analsis _de _rendiiento_Matriz10000x10000.ipynb`

### Overview

This notebook explores the Jacobi iterative method and computational performance for large matrix problems.

The Jacobi method is a classical numerical technique for solving systems of linear equations.

### Mathematical Problem

```text
Ax = b
```

Where:

- A is the coefficient matrix.
- x is the unknown vector.
- b is the known vector.

### Jacobi Iteration

For each variable:

```text
x_i(k+1) =
(b_i - Σ a_ij × x_j(k)) / a_ii
```

The summation excludes j = i.

### Main Concepts

- Numerical linear algebra.
- Matrix operations.
- Iterative solvers.
- Convergence.
- Computational performance.
- Memory requirements.
- Sequential and parallel execution.

### Large Matrix Context

The filename identifies experiments involving a matrix of size:

```text
10,000 × 10,000
```

A dense matrix of this size contains:

```text
100,000,000 elements
```

For double-precision floating-point storage, the matrix alone may require approximately 800 MB of memory, excluding additional arrays and computational overhead.

### Educational Objectives

- Study numerical iteration.
- Evaluate convergence conditions.
- Understand memory requirements.
- Explore computational efficiency.
- Examine the scalability of matrix operations.

### Important Considerations

The Jacobi method does not converge for every matrix.

Convergence depends on the mathematical properties of the coefficient matrix and the numerical configuration.

Large matrix experiments should also be executed with appropriate memory and processing resources.
